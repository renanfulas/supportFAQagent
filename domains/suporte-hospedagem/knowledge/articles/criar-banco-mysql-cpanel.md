# Como crio um banco de dados MySQL no cPanel

Use este artigo quando a duvida e criar um banco de dados MySQL no cPanel da
hospedagem.

Passos:

- no cPanel, procure por Bancos de dados MySQL
- em Novo banco de dados, informe um nome e clique em Criar banco de dados
- em Usuarios do MySQL, crie um usuario com senha e clique em Criar usuario
- em Adicionar usuario ao banco de dados, selecione o banco e o usuario
- marque Todos os privilegios e clique em Fazer alteracoes

Checklist inicial:

- anote nome do banco, usuario e senha exatamente como aparecem no cPanel
- use esses mesmos dados na configuracao do site ou do sistema
- para importar dados, use o phpMyAdmin

Quando escalar para humano:

- o sistema continua sem conectar mesmo com banco, usuario e privilegios corretos
- o banco aparece corrompido ou nao abre no phpMyAdmin
