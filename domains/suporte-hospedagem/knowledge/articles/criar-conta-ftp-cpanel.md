# Como crio uma conta de FTP no cPanel

Use este artigo quando a duvida e criar uma conta de FTP no cPanel da hospedagem
para enviar arquivos do site.

Passos:

- no cPanel, procure por Contas de FTP
- informe o usuario (login) e selecione o dominio
- defina e confirme uma senha forte
- em Diretorio, deixe a pasta do usuario ou use public_html para acesso a raiz
- defina a cota em MB ou deixe ilimitado
- clique em Criar conta de FTP

Checklist inicial:

- depois de criada, a conta de FTP nao pode ser editada; para mudar, exclua e
  crie de novo
- conecte com um cliente de FTP como o FileZilla usando os dados criados
- o endereco do servidor de FTP esta nos dados de acesso da sua hospedagem

Quando escalar para humano:

- a conexao de FTP falha mesmo com usuario, senha e servidor corretos
- precisa enviar arquivos acima do limite que o painel aceita
