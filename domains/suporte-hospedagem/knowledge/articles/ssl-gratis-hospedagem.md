# Como funciona o SSL gratis na minha hospedagem

Use este artigo quando a duvida e o certificado SSL gratuito do site hospedado
na HostGator (cadeado de site seguro e HTTPS).

Como funciona:

- o SSL gratis e instalado automaticamente para os dominios da hospedagem
- a instalacao so comeca depois que o dominio esta propagado apontando para a
  HostGator
- apos a propagacao, o SSL e instalado de forma automatica em ate 24 horas

Checklist inicial:

- confirme que o DNS do dominio aponta para a hospedagem
- aguarde a propagacao do DNS antes de esperar o SSL
- depois de ativo, ajuste o site para forcar HTTPS se ainda abrir em HTTP

Quando escalar para humano:

- o SSL nao ativa mesmo apos 24 horas com o dominio propagado
- o site mostra aviso de nao seguro depois do SSL instalado
