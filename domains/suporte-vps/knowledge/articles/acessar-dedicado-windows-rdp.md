# Como acesso meu Servidor Dedicado Windows por RDP

Use este artigo quando a duvida e acessar o Servidor Dedicado Windows da
HostGator pela area de trabalho remota (RDP).

Passos para conectar por RDP:

- pressione Windows + R, digite mstsc e clique em OK
- informe o IP do servidor com a porta na janela de conexao
- use o usuario informado no e-mail de ativacao (geralmente ServerAdmin)
- informe a senha enviada no e-mail de ativacao
- clique para conectar e acessar o Windows Server

Primeiros passos depois de acessar:

- entre no Portal do Cliente para gerenciar o servidor
- registre ou configure o DNS do dominio apontando para o servidor
- crie contas de e-mail pelo painel Plesk e publique o site

Quando escalar para humano:

- nao localiza o IP, a porta, o usuario ou a senha no e-mail de ativacao
- a conexao RDP falha mesmo com os dados corretos
